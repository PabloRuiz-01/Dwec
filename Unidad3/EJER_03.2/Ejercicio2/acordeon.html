Preguntas frecuentes

  • ¿Qué es HTML?

    HTML es un lenguaje de marcado utilizado para estructurar páginas web.

  • ¿Qué es CSS?

    CSS es un lenguaje que permite dar estilo y diseño a las páginas web.

  • ¿Qué es JavaScript?

    JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web.
